# climex: Climate Data of Mexico from the NASA POWER API

Climate data of Mexico from the NASA POWER API (daily, monthly or
climatological temperature, precipitation, humidity, wind and radiation)
for the 2,465 municipalities of Mexico or any set of points. One request
per point with all the period, up to five at a time, with retries; the
download can be stopped and resumed, and the result has one row per
point and date.
